# Customer Churn Prediction Using Machine Learning

A machine learning project that predicts customer churn using customer data and identifies patterns that may indicate whether a customer is likely to leave a company. The project combines data preprocessing, exploratory data analysis, predictive modeling, and performance evaluation to generate insights that can support customer retention strategies.

## 🚀 Live Demo

**Live Demo:** https://customer-churn-prediction-3szdjirybf5hqjk3a5anl6.streamlit.app/

## 📌 Project Overview

Customer churn occurs when customers stop using a company's products or services. Predicting churn helps businesses identify customers who may leave and take proactive steps to improve customer satisfaction and retention.

This project applies machine learning techniques to customer data to predict churn and explore the factors associated with customer behavior.

The project demonstrates an end-to-end machine learning workflow, from preparing the dataset to building predictive models and presenting results through an interactive application.

## 🎯 Objectives

* Analyze customer data to understand churn patterns.
* Clean and preprocess data for machine learning.
* Perform Exploratory Data Analysis (EDA) to identify important trends.
* Prepare relevant features for predictive modeling.
* Train a machine learning model to predict customer churn.
* Evaluate model performance using appropriate classification metrics.
* Present predictions through an interactive Streamlit application.
* Generate insights that can help businesses develop customer retention strategies.

## ⚙️ Project Workflow

### 1. Data Collection

Load the customer dataset containing relevant information about customer profiles, account activity, and churn status.

### 2. Data Preprocessing

Prepare the dataset for analysis and model training by handling missing values, encoding categorical variables, and selecting relevant features where necessary.

### 3. Exploratory Data Analysis (EDA)

Explore customer characteristics and identify patterns associated with churn using statistical analysis and visualizations.

### 4. Feature Engineering

Prepare meaningful input features for the machine learning model based on the available customer attributes.

### 5. Model Training

Train a classification model to predict whether a customer is likely to churn. Model selection depends on the dataset, preprocessing pipeline, and evaluation results.

### 6. Model Evaluation

Evaluate predictive performance using appropriate classification metrics, such as:

* Accuracy
* Precision
* Recall
* F1-Score
* ROC-AUC, where applicable

These metrics provide a more complete understanding of model performance than accuracy alone.

### 7. Interactive Deployment

Deploy the prediction application using Streamlit so users can interact with the model through a web interface.
